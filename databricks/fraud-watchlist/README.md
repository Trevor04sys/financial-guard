# Fraud Watchlist

This directory contains the fraud watchlist source data and ingestion utility.

Expected files:

- `fraud_watchlist_data_generator.py.py` – Converts watchlist CSV records into individual JSON files for ingestion through Databricks Auto Loader.
- `fraud_watchlist.csv` – Synthetic fraud watchlist input data.

Review the CSV and generated JSON files for personal or sensitive information before publishing them.
