# Financial Guard Dashboard Evidence

This directory contains screenshots of the Financial Guard monitoring dashboard.

The dashboard includes four pages:

1. **Executive Overview** — Transaction volume, fraud alerts, high-value alerts, and transaction trends.
2. **Fraud Analytics** — High-risk alerts and fraud-related insights.
3. **Customer & Transaction Insights** — Customer and transaction-level analysis.
4. **Watchlist Monitoring** — Watchlist entries and monitoring statistics.

The screenshots represent historical dashboard snapshots from the synthetic demonstration environment. They should not be interpreted as live production metrics.
