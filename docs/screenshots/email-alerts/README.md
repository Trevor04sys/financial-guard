# Email Alert Evidence

This directory contains sample email notifications generated by Financial Guard.

- `01-high-value-transaction-email-example-TXF379185.pdf` — Example high-value transaction alert.
- `02-fraud-watchlist-email-example-TXF465194.pdf` — Example fraud watchlist alert.

These emails demonstrate the notification mechanism configured for the project.

The examples are historical demonstrations using synthetic transaction data and do not represent a currently operational email service.
