# Project Screenshots

This directory contains visual evidence of the Financial Guard project.

- `kafka/` — Kafka topics and messages.
- `watchlist/` — Fraud watchlist sample records.
- `databricks-pipeline/` — Databricks pipeline execution.
- `databricks-tables/` — Bronze, Silver, and Gold table evidence.

- `email-alerts/` — Sample email alert evidence.

Sensitive information should be redacted before public sharing.
